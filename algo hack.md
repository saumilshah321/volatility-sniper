# Algo-Trading Hackathon × Internship Drive

#### E-Summit 2026 | Powered by BatraHedge

## 1. About the Event

The **Algo-Trading Hackathon × Internship Drive** is a two-stage FinTech event conducted as part of
**E-Summit 2026** , designed to evaluate students on their ability to **think quantitatively, build
logical trading systems, and present solutions through intuitive user interfaces**.

```
Participants are expected to demonstrate not only algorithmic correctness but also how such
systems would be used in real-world trading environments.
```
```
Your willingness to be part of BatraHedge and your openness to learning will be considered as
part of your evaluation for the internship opportunity at BatraHedge followed by in-person
interviews.
```

## 4. Dataset & Resources

```
● A customised dataset link provided by BatraHedge will be shared with participants
● Dataset must be used exclusively
● External datasets are not permitted
```
## 5. Problem Statement

```
Participants are required to design, implement, backtest, and present an algorithmic trading system
using the provided dataset, along with a functional and intuitive UI/UX interface that visualises
strategy performance and decision-making.
The solution should reflect how a real trading or analytics platform would operate.
```
