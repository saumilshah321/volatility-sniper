# Deployment Instructions

## Streamlit Cloud Deployment (Recommended)

### Quick Deploy (2 minutes)

1. **Go to**: https://share.streamlit.io/

2. **Sign in** with GitHub

3. **Click "New app"**

4. **Fill in the form**:
   - Repository: `saumilshah321/volatility-sniper`
   - Branch: `main`
   - Main file path: `app.py`

5. **Click "Deploy"**

6. **Wait 2-3 minutes** for deployment

7. **Copy the public URL** (format: `https://saumilshah321-volatility-sniper-xxxxxxx.streamlit.app`)

### Deployment URL

**Your app will be live at**: 
```
https://<username>-<repo>-<hash>.streamlit.app
```

This URL is what you'll submit in the Google Form!
